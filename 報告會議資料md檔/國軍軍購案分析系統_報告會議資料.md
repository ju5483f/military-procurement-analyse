# 報告事項：國軍軍購案分析系統之研發歷程與審核應用

## (一) 緣起

　　近年來，隨資訊科技快速發展及國際審計思潮之轉變，本部積極推動數位審計，導入風險導向審計理念，運用各類資訊工具強化財務監督效能，以有限之審計人力遂行日益龐雜之查核任務。就國防審計而言，立法院於115年5月8日三讀通過「保衛國家安全及強化不對稱戰力計畫採購特別條例」，規劃於8年期間編列7,800億元對美軍購特別預算，採購保衛國家安全及強化不對稱戰力之武器及裝備，並明定審計機關應依法辦理審計。前開預算規模龐鉅，且後續執行成效攸關國家安全，社會各界關注日殷，如何在資源有限之情形下，精準辨識高風險軍購案件、集中查核資源、提升選案效率，實為當前國防審計之重要課題。

　　按國防部為加強國軍對美軍購執行、驗收、結案及軍購案備查帳管制作業，訂有相關作業要點，並運用軍購管理系統、軍購案備查帳帳務處理系統等資訊系統，結合各軍種軍購管制會議及督導機制，管控軍購案之執行。國防部主計局並每半年檢送「執行中軍購案個案管制表」（下稱管制表）等資料，供本部審核參考，其中包括發價值、累積結匯值、累積交運值、累計結匯率、累計交運率及軍購備查帳餘額等欄位，表達各軍購案之執行現況。本部審計同仁向依歷次查核經驗，就管制表所載資料逐案套用多項分析條件（下稱控制點），如「累計交運值／發價值」與「累計結匯率」兩者差距達百分之四十以上等，藉以初步篩選履約落後或帳務異常之風險案件，作為深入查證之依據。

　　惟前開管制表屬機敏資料，僅能由承辦同仁每半年將機密來函資料匯入實體隔離區，於機密電腦內以Excel逐案、逐條件人工操作，作業繁瑣費時，且於反覆計算與抄錄過程中易生漏誤；又因機密電腦無法連結外部網路，近年興起之Python程式語言、大型語言模型及各類雲端分析工具均無從運用，藉資訊科技提升審計工作效率之程度甚為有限。凡此，均使軍購案之風險篩選長期倚賴人工，難以充分發揮數位審計之效能。

　　尤有進者，軍購案自結匯付款至交運結案，往往歷經數年，其執行狀態隨每半年檢送之管制表而遞嬗，本須就同一案件跨期追蹤、觀察其風險之積累與變化；然人工作業之標準難期一致、歷次結果亦不易併同比對，致風險案件之演變趨勢難以有效掌握，殊為可惜。是以，如何在不牴觸機敏規範之前提下，將審計同仁之查核經驗轉化為可反覆運行、跨期一致之分析工具，俾兼顧效率、正確與保密，即為本系統研發之初衷。

　　本部爰思考在嚴守機敏安全之前提下，如何運用資訊技術改善前述人工作業之困境。經提報「國軍軍購案相關數據分析精進作為」，規劃「設計可於離線環境運行之管制表簡易分析程式」、「研議軍購資料與分析結果交互勾稽之可行性」及「研議建置軍購風險熱區氣泡圖」等三大精進方向，並著手研發「國軍軍購案分析系統」（下稱本系統），期以資訊工具輔助審計專業判斷，降低承辦同仁負擔，並提升軍購案選案之效率與精準度。本報告謹就本系統之研發緣起、現況挑戰、因應對策及理念精神，臚述如次。

## (二) 現況及挑戰

　　軍購案帳務關係之特殊性，加以機敏資料處理之限制，構成本系統研發過程所須克服之主要挑戰，分述如下：

1. **軍購案採「先付款後交貨」制度，帳務結構複雜，風險辨識高度倚賴專業經驗，難以一望即知**：

   國軍對美軍購多以「外國軍事銷售」（FMS）方式辦理，其金流與一般採購迥異。我方須依發價書及美方每季帳單先行結匯付款，款項存入美國聯邦儲備銀行（FRB）之計息帳戶，再由美方按未來實際需求逐月自FRB提領動支，俟交貨後於季帳單列計交運值，我方始得辦理驗收並沖銷在途物資。是以「軍購備查帳餘額」（即結匯值減交運值）代表「已付款、尚未交貨、滯存美方」之在途物資金額，向為審計檢討之核心焦點；而FRB餘額之高低，則反映付款是否顯著超前美方之實際需求。此外，作業維持案多採開放式合約，藉一號訂單預建常備零附件庫存、再以二號訂單申請動用，案內常無實際交運品項，其帳務型態與軍事投資建案復有不同。凡此先付後交、跨年執行之帳務結構，牽涉結匯率、交運率、備查帳餘額、FRB餘額、待平衡支付值等多項數據，異常態樣繁多且彼此交錯，風險辨識高度倚賴審計人員對制度與帳務之熟稔，殊難僅憑表面數字逕予判斷。

2. **控制點項目與案件數量龐大，人工逐案套用耗時費力且易生漏誤，跨期一致性亦不易維持**：

   每半年檢送之管制表動輒數百案，每案又須逐一套用多項控制點，且各控制點涉及比率運算、絕對值計算、金額門檻比較，並須防範除以零等例外情形。承辦同仁於機密電腦內以Excel逐格操作，不僅曠日費時，於大量重複性計算與抄錄之際，亦難免發生計算或登錄錯誤。又因作業高度倚賴人工判斷，不同承辦人員、不同期間所適用之標準難期完全一致，影響同一案件跨期比較之基礎，不利於掌握風險案件之演變趨勢。

3. **分析結果同屬機敏資料，難與軍購管制會議紀錄等資料交互勾稽，應用價值受限**：

   控制點篩選之結果仍屬機敏資料，難以再與各軍種軍購案管制會議紀錄、軍購案備查帳等資料進行交互驗證。實務上，部分經篩選出之風險案件，可能業於各軍種軍購管制會議中檢討並研處，惟因缺乏勾稽比對之機制，審計人員無從即時確認風險案件之檢討情形，致查核資源未能有效聚焦於尚待處理之案件，分析結果之應用價值因而受限。

4. **風險高低缺乏量化與視覺化之基礎，選案倚賴主觀經驗，資源難以精準配置**：

   人工篩選僅能得出各案「命中」或「未命中」個別控制點之結果，無法進一步量化各案風險程度之高低，亦無跨案比較之整體視覺呈現。同一案件可能同時命中多項控制點，究係單一面向偏高、抑或執行與財務風險兼具，人工實難通觀全局；於面對數百件執行中軍購案時，究應優先查核何案、如何配置有限之查核人力，多倚賴審計人員之主觀經驗與逐案翻查，缺乏客觀、一致且可跨期比較之量化依據，選案之精準度與資源配置之效率均有提升空間。

## (三) 因應對策

　　為克服前開挑戰，本系統秉持「以審計專業為本、資訊工具為輔」之核心理念，於確保機敏安全之前提下，分階段建置各項功能，使審計人員得由「逐案人工檢視」進而「量化精準選案」。茲將主要對策說明如下：

1. **建置離線單機、單一自足之分析程式，嚴守機敏資料處理規範**：

   本系統設計為單一之網頁（HTML）檔案，並已將試算表解析等所需元件一併內嵌其中，毋須安裝任何軟體、毋須連結網路，於機密區之實體隔離電腦上以瀏覽器直接開啟即可使用。承辦同仁僅須將國防部來函檢送之管制表匯入，系統即於本機記憶體內完成全部運算，不上傳任何資料至外部伺服器，關閉瀏覽器後資料即行清除。如此，一方面使資訊分析得以在實體隔離之機密環境中運行，突破過往無法運用資訊工具之限制；另一方面亦完全符合機敏資料不得外洩之要求，在效率與保密之間取得妥適平衡。

2. **以審計經驗淬鍊之控制點為核心，沿軍購金流節點設計風險篩選條件**：

   本系統之控制點並非機械式之數字比對，而係將歷年查核經驗具體化，沿「款項之旅程」逐一對應各風險節點而設計，俾能貼近軍購帳務之實質風險。其設計邏輯概如下表：

   | 金流節點 | 風險意涵 | 控制點設計重點 |
   | :--- | :--- | :--- |
   | 結匯付款 | 付款超前美方實需、資金大量滯存FRB | 結匯率逾100%（溢付帳務異常）、FRB餘額佔結匯值比率偏高 |
   | 美方提領 | 已自FRB提領動支卻無交運，履約異常 | 交運值不及已提領金額之一成，且差額重大 |
   | 交運驗收 | 交運進度落後付款進度、在途物資偏高 | 交運率未達門檻、付款與交運差異達門檻且備查帳餘額重大 |
   | 例外態樣 | 帳務異常或我方積欠案款 | 結匯率逾100%、待平衡支付值大於0（欠款案件） |

   為求周妥，控制點並依案件性質分流設計，區分為「軍事投資建案」及「作業維持案」兩類，各訂10項，合計20項。其中就成對之控制點採「比率＋金額雙保險」設計，由比率負責辨識異常型態、由絕對金額門檻負責捕捉滯美資金重大之大案，互補防漏；又因作業維持案多屬開放式軍購、結匯先行而分批交運之常態，其判斷門檻與軍事投資建案刻意有別，以避免小額案件產生過多雜訊。凡此差異，均係基於審計專業之考量，而非任意設定，與本部所訂軍購案數位審計異常指標一脈相承並予深化。

3. **導入軍購管制會議紀錄交互勾稽，擴大分析結果之應用價值**：

   針對分析結果難與外部資料交互驗證之問題，本系統於風險篩選之後，增設會議紀錄核對功能。系統可將控制點篩選出之風險案件，與各軍種軍購管制會議紀錄之整理檔以案號自動勾稽比對，標示業經會議檢討之案件及其檢討態樣、辦理情形；同一案件於多次會議或多份資料中經檢討者，並予併同呈現。如此，審計人員即得將機敏之分析結果與相對公開之會議資料交互印證，一則確認風險案件之研處情形，二則得聚焦於尚未檢討或研處未臻妥適之案件，使查核資源之配置更為妥適，並擴大控制點分析結果之應用價值。此亦落實前開發想「將軍購資料與分析結果交互勾稽」之規劃方向。

4. **建置風險評分與風險分布氣泡圖，量化風險程度並提升選案效率**：

   為使風險高低得以量化並視覺化呈現，本系統進一步就當期全部軍購案逐案評分。系統依各案命中控制點所對應之風險，按其嚴重程度計以分數，並將各項評分項目歸為「執行風險」與「財務風險」兩類分別加總：凡涉及交運進度落後、履約異常者，歸入執行風險；凡涉及資金滯存美方、帳務溢付、積欠案款者，歸入財務風險。二者加總即為各案之風險總分，俾以客觀分數表達各案風險之相對高低及其性質。又評分係採固定之數值基準（錨點）計算，而非按當期案件相互排序，其用意在使不同期間之分數具有一致之衡量基礎；蓋若按當期排序計分，同一案件於不同期間之分數將隨當期其他案件之多寡而浮動，無從跨期比較，此與前述追蹤風險演變趨勢之需求正相扞格，爰採數值錨點法，確保跨期之可比性。

   在此基礎上，系統另建置「風險分布氣泡圖」，以橫軸表達執行風險、縱軸表達財務風險，將各軍購案依其風險分數定位於圖上，並以氣泡大小表達該案發價值（案件規模），復依風險總分劃分風險分區，並標示風險名列前段之案件。軍事投資建案與作業維持案分別繪製，且兩圖均採相同之固定尺度，俾利跨圖、跨期對照。審計人員藉此得一目瞭然掌握全部案件之風險分布，迅速辨識落於高風險區、且金額龐大之案件，並可就特定區塊放大檢視、搭配定位示意圖掌握所在位置，將查核資源集中投注於最需關注之案件。此即前開發想「軍購風險熱區氣泡圖」之具體實現，對提升選案效率助益甚大。

5. **實地驗證與滾動精進，確保分析結果之正確性與操作之簡便性**：

   本系統之研發採循序漸進、逐步擴充之方式進行：由初期之分析條件，逐步充實至20項控制點，並陸續納入會議紀錄勾稽、風險評分及風險分布氣泡圖等功能。為確保系統計算結果之正確性，各階段均以模擬資料獨立驗算，並就系統輸出與人工作業結果逐案比對，力求完全一致；復帶入機密區實地測試，就承辦同仁反映之操作與顯示問題（如用語之明確性、氣泡圖之縮放與定位、明細資訊之呈現方式等）持續檢討修正，使系統更貼近實務需求、更便於操作。

   尤須說明者，風險評分所採之數值基準（錨點），須參酌真實案件之金額分布方能妥適設定，而該等分布資料僅存於機密區，無從攜出。為此，另設計一獨立之錨點校準輔助工具，於機密區匯入真實管制表後，由系統試算並提供各項基準之建議值供參，惟基準之最終設定，仍屬審計人員之政策判斷，且僅將該少數判斷後之數字帶回，真實金額資料則全程留於機密區，不隨之外流。凡此，均係為在確保機敏安全之前提下，兼顧分析基準之合理性所為之設計。至控制點、風險評分及氣泡圖等分析架構，均係本部依查核經驗自主發展而成，並將隨軍購實務及查核重點之演進，滾動檢討其妥適性與有效性。

## (四) 結語

　　本系統以單一離線檔案之形式，將原須耗費數日之人工篩選作業，簡化為「匯入即得」，大幅降低人工計算與抄錄之漏誤風險；並透過會議紀錄勾稽及風險之量化、視覺化，使審計人員得由逐案檢視進而精準選案，將有限之查核資源集中於高風險案件。尤以本系統全程於實體隔離環境運行、資料不外傳，在嚴守機敏安全之前提下實現資訊分析之效能，兼顧效率與保密，允為機敏審計環境下運用資訊工具之一項具體嘗試。

　　面對對美軍購特別預算規模龐鉅、社會關注日殷之審計環境，本系統之研發，正呼應本部「智慧審計」與「韌性審計」之推動方向——以資訊工具輔助審計專業判斷，強化軍購案之風險辨識與選案精準度，並落實從傳統事後查核轉向前瞻預警治理之理念。惟須強調者，本系統之價值不在於取代審計人員之專業判斷，而在於將審計同仁多年淬鍊之查核經驗，轉化為可反覆運用、跨期一致之分析工具，使專業經驗得以傳承並放大其效益；控制點之增修、評分基準之設定、風險案件之最終認定，仍須回歸審計人員之專業與經驗，資訊系統始終居於輔助之地位。

　　另本系統採單一自足檔案之設計，毋須連網、毋須安裝，於機密區既有之電腦環境即可運行，維護與部署成本低，且核心之分析架構清楚透明、便於檢視與調整，日後如控制點或評分邏輯有所變動，均得隨之更新，具有相當之延展性。此一「以簡馭繁」之作法，亦可供本部其他機敏資料分析場合參考援用。

　　展望未來，本部將持續精進本系統各項功能、擴大資料勾稽之範圍，並配合「保衛國家安全及強化不對稱戰力計畫採購特別條例」相關查核作業之推展，深化軍購案查核之深度與廣度，善盡審計監督職責，促進國防資源運用之效益及軍購之良善治理，積極回應立法院、監察院及社會大眾對審計機關之期待，創造最大之審計價值。
